# Sistema de Registro de Estudiantes

Proyecto de práctica para aprender gestión de trabajo mediante GitHub Issues y GitHub Projects.

## Funcionalidades previstas

- Registro de estudiantes.
- Registro de materias.
- Generación de reportes.
- Documentación del sistema.

## Objetivo de la práctica

Organizar las tareas del proyecto utilizando:

- Issues
- Assignees
- Labels
- Milestones
- GitHub Projects
- Kanban
